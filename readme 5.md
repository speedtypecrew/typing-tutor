## Overview

**Project Title**: Typing Tutor

**Project Description**: An online typing game web app to help users improve their typing ability

**Project Goals**: Create a Django framework that hosts a robust typing game

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make sure to install the updated version of django
2. Create a new respository for the django project
3. Create view, models, urls for each page/app you would like
4. Path urls correctly
5. Create html templates for each view
6. Use css to make the web app more usable and pretty

Instructions for using the software:

1. Navigate to the host directory for the webapp
2. Type "py manage.py runserver" into the console
3. You will see an output with an IP address. Click on that address
4. Navigate the application however you would like
